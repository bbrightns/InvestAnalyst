# กรณีศึกษา: AMD (Case Study: AMD)

> [คู่มือฉบับมืออาชีพ (The Professional's Playbook)](learning-playbook.html) ได้สอนกระบวนการวนลูป (Loop) กับหุ้นเติบโตทบต้นแบบเติบโตเต็มวัย (Mature Compounder) อย่าง Apple ไปแล้ว ในบทนี้เราจะนำ **กระบวนการ 10 ขั้นตอนเดียวกันนี้ ตั้งแต่ต้นจนจบ มาปรับใช้กับหุ้นที่มีลักษณะแตกต่างกันอย่างสิ้นเชิง: Advanced Micro Devices (AMD)** — หุ้นเซมิคอนดักเตอร์เติบโตสูงและมีความเป็นวัฏจักร (Cyclical, High-Growth Semiconductor) ซึ่งอยู่ใจกลางกระแสการลงทุนด้าน AI ลองสังเกตว่ากระบวนการที่เหมือนกันทุกประการนี้นำไปสู่การตัดสินใจ ขนาดของสถานะลงทุน (Position Size) และแผนการเทรดที่แตกต่างกันอย่างสิ้นเชิงได้อย่างไร **ข้อมูลและข้อเท็จจริงทั้งหมดของบริษัทเป็นเรื่องจริง ตัวเลขทางการเงินทุกตัวเป็นตัวเลขสมมุติและปัดเศษเพื่อการเรียนการสอนเท่านั้น — ไม่ใช่ข้อมูลปัจจุบัน และไม่ใช่คำแนะนำการลงทุน**

**สิ่งที่คุณจะได้เรียนรู้**

- วิธีประยุกต์ใช้กระบวนการลูปตามคู่มือกับหุ้น **เติบโตตามวัฏจักร (Cyclical Growth)** ไม่ใช่หุ้นที่โตสม่ำเสมอทบต้นเรื่อยๆ
- เหตุใดปราการทางธุรกิจ (Moat), การประเมินมูลค่า (Valuation) และโปรไฟล์ความเสี่ยงของ AMD จึงจำเป็นต้องมี **ขนาดสถานะลงทุน (Position Size)** และแผนการที่แตกต่างออกไป
- ปราการด้านซอฟต์แวร์ที่ด้อยกว่า (เมื่อเทียบกับ NVIDIA) และความเป็นวัฏจักรที่รุนแรงเปลี่ยน **สมมติฐานการลงทุน (Thesis)** อย่างไร
- ตัวชี้วัดผลงานหลัก (KPIs) และ **เงื่อนไขลบล้างสมมติฐาน (Invalidation Triggers)** ใดบ้างที่มีความสำคัญอย่างแท้จริงสำหรับการเดิมพันในหุ้นเซมิคอนดักเตอร์ AI
- กระบวนการลูปที่มีวินัยแบบเดียวกันนี้ช่วยปกป้องคุณได้อย่างไรเมื่อเผชิญกับความไม่แน่นอนสูง

> หากคุณยังไม่ได้อ่าน ขอแนะนำให้เริ่มต้นจาก [คู่มือกลยุทธ์ (Playbook)](learning-playbook.html) — หน้านี้จะอ้างอิงและต่อยอดจากกระบวนการ 10 ขั้นตอนดังกล่าว

## ขั้นตอนที่ 0 · ทำความรู้จักบริษัท (Step 0 · Meet the company)

**AMD** ออกแบบชิปประมวลผล CPU และ GPU โดยดำเนินธุรกิจผ่าน 4 กลุ่มส่วนงาน (Segments) และกำลังอยู่ในสมรภูมิการแข่งขัน 2 ด้านพร้อมกัน:

| ส่วนงาน (Segment) | รายละเอียดธุรกิจ (What it is) | คู่แข่งหลัก (Competes with) |
|---------|-----------|---------------|
| **ศูนย์ข้อมูล (Data Center)** | CPU สำหรับเซิร์ฟเวอร์ (EPYC) + AI GPU (Instinct MI300) | Intel (CPU), **NVIDIA** (AI GPU) |
| **คอมพิวเตอร์ลูกข่าย (Client)** | ชิป Ryzen สำหรับ PC และแล็ปท็อป | Intel |
| **เกมมิ่ง (Gaming)** | ชิปสำหรับเครื่องคอนโซล + การ์ดจอ Radeon | NVIDIA, คอนโซลต่างๆ |
| **ระบบสมองกลฝังตัว (Embedded)** | ชิป FPGA และชิปแบบปรับโครงสร้างได้ (Adaptive Chips จากดีลควบรวม Xilinx) | คู่แข่งหลากหลายราย (Broad) |

สมมติฐานการลงทุนทั้งหมดในปัจจุบันขึ้นอยู่กับสิ่งเดียว: **ศูนย์ข้อมูล (Data Center)** ซึ่งตัวเร่งประมวลผล AI (AI Accelerators) คือขุมทรัพย์รางวัลใหญ่ที่ NVIDIA กำลังครองตลาดอยู่ สมมติว่าการดึงข้อมูลของเราได้ตัวเลข **สมมุติและปัดเศษ** ดังต่อไปนี้:

| ภาพรวมสถิติ (ตัวเลขสมมุติ) (Snapshot) | ค่า (Value) |
|-------------------------|-------|
| ราคาหุ้น (Share price) | ~$135 |
| จำนวนหุ้นที่จำหน่ายได้แล้ว (Shares outstanding) | ~1.62 พันล้านหุ้น (B) |
| มูลค่าหลักทรัพย์ตามราคาตลาด (Market cap) | ~$220 พันล้านดอลลาร์ (B) |
| รายได้รวมย้อนหลัง 12 เดือน (Revenue TTM) | ~$25 พันล้านดอลลาร์ (B) |
| อัตรากำไรขั้นต้นตามมาตรฐานบัญชี (GAAP gross margin) | ~50% |
| อัตรากำไรจากการดำเนินงานตามมาตรฐานบัญชี (GAAP operating margin) | ~5–7% (ถูกกดดันจากค่าตัดจำหน่ายดีล Xilinx ประมาณ ~$3 พันล้านดอลลาร์/ปี) |
| อัตรากำไรจากการดำเนินงานแบบปรับปรุง (Non-GAAP operating margin) | ~20%+ |
| กำไรสุทธิตามมาตรฐานบัญชี (Net income GAAP) | ~$1.6 พันล้านดอลลาร์ (EPS บางมาก) |
| กระแสเงินสดอิสระ (Free cash flow - FCF) | ~$3–4 พันล้านดอลลาร์ (B) |
| ฐานะงบดุล (Balance sheet) | เงินสดสุทธิ (Net cash / หนี้สินต่ำ) |
| Forward P/E (P/E ล่วงหน้า) | ~35–45× |

> **แนวคิดสำคัญ (Key idea):** เพียงเริ่มต้นก็เห็นได้ชัดว่าภาพนี้ไม่เหมือนกับ Apple เลย กำไรตามมาตรฐาน GAAP ที่บางเฉียบ การประเมินมูลค่ามหาศาลที่อิงอยู่กับกำไรใน *อนาคต* และธุรกิจที่ผลประกอบการเหวี่ยงไปตามวัฏจักรของอุตสาหกรรมเซมิคอนดักเตอร์ แม้กระบวนการวิเคราะห์จะเหมือนกัน แต่ "หน้าปัดการปรับค่า" จะต้องปรับเปลี่ยนไปอย่างมาก

## ขั้นตอนที่ 1 · เขียนสมมติฐานการลงทุนก่อนเป็นอันดับแรก (Step 1 · Write the thesis first)

> **สมมติฐานการลงทุน (Thesis):** *AMD คือผู้เล่นอันดับ 2 ที่น่าเชื่อถือในตลาดการประมวลผลศูนย์ข้อมูล AI หาก AMD สามารถชิงส่วนแบ่งแม้เพียงเล็กน้อยในตลาดตัวเร่งประมวลผล AI ที่กำลังเติบโตอย่างรวดเร็ว ควบคู่ไปกับการแย่งชิงส่วนแบ่งตลาด Server CPU จาก Intel ได้อย่างต่อเนื่อง รายได้และอัตรากำไรของกลุ่ม Data Center จะขยายตัวมากพอที่จะเติบโตจนสอดรับ — และก้าวข้าม — มูลค่าหุ้นในปัจจุบันที่ซื้อขายกันในระดับพรีเมียมได้*

มุมมองสองด้าน (Bull vs. Bear) — และในกรณีนี้ มุมมองเชิงลบ (Bear case) นั้น *แข็งแกร่งมาก* ซึ่งตัวมันเองถือเป็นข้อมูลชิ้นสำคัญ:

| มุมมองเชิงบวก (Bull case) | มุมมองเชิงลบ (Bear case) |
|-----------|-----------|
| ตลาดเป้าหมายรวม (TAM) ของตัวเร่งประมวลผล AI นั้นมหาศาลและกำลังเติบโต ผู้เล่นอันดับ 2 สามารถสร้างผลตอบแทนได้มหาศาล | ระบบนิเวศซอฟต์แวร์ **CUDA** ของ NVIDIA เป็นปราการทางธุรกิจที่ลึกมาก ส่วน ROCm ของ AMD ยังตามหลังอยู่ |
| EPYC ยังคงแย่งชิงส่วนแบ่งตลาด Server CPU จาก Intel ได้อย่างต่อเนื่อง | อุตสาหกรรมเซมิคอนดักเตอร์มีความเป็น **วัฏจักร (Cyclical)** ส่วนงาน Client/Gaming อาจทรุดตัวลงอย่างหนักได้ |
| Xilinx (Embedded) ช่วยเพิ่มรายได้ที่มีอัตรากำไรสูงกว่าและมีความต่อเนื่องเหนียวแน่น (Sticky) | การประเมินมูลค่าในปัจจุบันได้สะท้อนความสำเร็จด้าน AI ไปแล้ว — ทำให้มีส่วนเผื่อความผิดพลาด (Margin for error) น้อยมาก |
| งบดุลที่มีเงินสดสุทธิ (Net-cash) ช่วยรองรับการลงทุนวิจัยและพัฒนา (R&D) ผ่านทุกช่วงวัฏจักร | การกระจุกตัวของลูกค้า; ผู้ให้บริการคลาวด์รายใหญ่ (Hyperscalers) ต่างกำลังพัฒนาชิปของตนเองขึ้นมาใช้เองเช่นกัน |

*ใน Plugin:* เครื่องมือ `stock-eval` ช่วยอ่านค่าคุณภาพ/มูลค่า/การเติบโตได้อย่างรวดเร็ว ขณะที่ `competitor-analysis` มีความจำเป็นอย่างยิ่งในเคสนี้ เพื่อประเมินเกรดของปราการทางธุรกิจอย่างตรงไปตรงมาเมื่อเทียบกับ NVIDIA และ Intel

## ขั้นตอนที่ 3 · เป็นธุรกิจที่ดีหรือไม่? (คุณภาพ) (Step 3 · Is it a good business? (quality))

วิเคราะห์ผ่าน [มุมมองด้านคุณภาพ (Quality lens)](learning-quality.html) — และให้คะแนนอย่างตรงไปตรงมา:

- **ผลตอบแทนจากเงินลงทุน (Returns on capital):** ROIC อยู่ในระดับ **ปานกลางและต่ำกว่า Apple** อีกทั้งยังถูกกดดันเพิ่มเติมจากค่าตัดจำหน่ายในดีล Xilinx แม้จะสร้างผลตอบแทนสูงกว่าต้นทุนทางการเงิน (WACC) ได้ในปีที่ดี แต่นี่ *ไม่ใช่* ธุรกิจเครื่องจักรผลิต ROIC ระดับ 50% มีความเป็นวัฏจักรสูง
- **อัตรากำไร (Margins):** อัตรากำไรขั้นต้นตาม GAAP ที่ ~50% ถือว่าน่าพอใจ และ *ทิศทางแนวโน้ม* (การปรับสัดส่วนผลิตภัณฑ์มุ่งสู่ Data Center + Embedded) คือตัวชี้วัดสำคัญ — อัตรากำไรที่เพิ่มขึ้น = สมมติฐานการลงทุนกำลังเป็นไปตามแผน
- **ปราการทางธุรกิจ (Moat) — จุดชี้ขาดสำคัญ:** CPU สถาปัตยกรรม x86 เป็นตลาด **กึ่งผูกขาดสองราย (Duopoly)** ที่มีความยั่งยืน (มี Moat ชัดเจนเมื่อแข่งกับ Intel) ทว่าในฝั่ง AI GPU ระบบนิเวศซอฟต์แวร์ **CUDA** ของ NVIDIA คือปราการที่แข็งแกร่งและกว้างมาก จุดเด่นของ AMD คือความคุ้มค่าด้านราคาต่อประสิทธิภาพ (Price/Performance) และการเป็นตัวเลือกทางเลือกที่น่าเชื่อถือ — ซึ่งถือเป็นปราการที่ **แคบกว่าและยังต้องแข่งขันขับเคี่ยวกันอยู่** เมื่อเทียบกับการผูกขาดระบบนิเวศ (Ecosystem Lock-in) ของ Apple
- **การจัดสรรเงินทุน (Capital allocation):** ให้ความสำคัญกับการวิจัยและพัฒนาเป็นอันดับแรก (R&D-first ซึ่งเป็นแนวทางที่ถูกต้องสำหรับการแข่งขันทางเทคโนโลยี); การซื้อหุ้นคืนอยู่ในระดับปานกลางและทำไปเพื่อชดเชยค่าตอบแทนในรูปหุ้นของพนักงาน (Stock-based compensation) เป็นหลัก มากกว่าที่จะเป็นการลดจำนวนหุ้นหมุนเวียนลงอย่างมีนัยสำคัญเหมือนอย่างกรณีของ Apple

**บทสรุป (Verdict):** เป็นธุรกิจที่ดีและกำลังพัฒนาดีขึ้น — แต่ **มีความเป็นวัฏจักรสูงกว่า ผลตอบแทนต่ำกว่า และมีปราการทางธุรกิจที่แคบกว่า** เมื่อเทียบกับกรณีของ Apple ด้านคุณภาพจึงจัดอยู่ในเกณฑ์ *ผ่านแบบมีเงื่อนไขและข้อควรระวัง (Pass with caveats)* ไม่ใช่เกณฑ์ยอดเยี่ยมแบบไร้ข้อกังขา

## ขั้นตอนที่ 4 · งบการเงินสนับสนุนสมมติฐานหรือไม่? (Step 4 · Do the statements back it up?)

วิเคราะห์ผ่าน [มุมมองงบการเงิน (Statements lens)](learning-statements.html) จุดสำคัญที่เป็นรายละเอียดซับซ้อนคือ: **กำไรตามมาตรฐาน GAAP ดูน้อยมาก แต่ส่วนใหญ่เกิดจากค่าตัดจำหน่ายที่ไม่ใช่เงินสด (Non-cash amortization)** จากการเข้าซื้อกิจการ Xilinx โดยกระแสเงินสดอิสระ (FCF) อยู่ที่ประมาณ ~$3–4 พันล้านดอลลาร์ ซึ่งสูงกว่ากำไรสุทธิตาม GAAP ที่ ~$1.6 พันล้านดอลลาร์ อย่างมาก — สะท้อนว่าธุรกิจสามารถสร้างกระแสเงินสดได้จริงมากกว่าที่ตัวเลขในงบกำไรขาดทุนแสดงไว้

- จับตา **การเปิดเผยข้อมูลรายส่วนงาน (Segment disclosure)**: รายได้และกำไรจากการดำเนินงานของ Data Center คือหัวใจหลักของสมมติฐานการลงทุนนี้ ขณะที่ส่วนงาน Client/Gaming อาจบดบังหรือทำให้ภาพรวมดูดี/แย่เกินจริงได้
- งบดุลอยู่ในสถานะ **เงินสดสุทธิ (Net cash)** — มีความเสี่ยงทางการเงินต่ำ ซึ่งมีความสำคัญอย่างยิ่งต่อการอยู่รอดผ่านช่วงขาลงของวัฏจักรเซมิคอนดักเตอร์
- ตรวจสอบสัญญาณเตือนภัย (Red-flag check): สินค้าคงเหลือ (Inventory) เพิ่มขึ้นเร็วกว่ายอดขายหรือไม่ (สัญญาณเตือนคลาสสิกของวัฏจักรเซมิคอนดักเตอร์ขาลง)? ในข้อมูลจำลองของเราคำตอบคือยังไม่พบ — แต่นี่คือสิ่งแรกที่ต้องตรวจสอบซ้ำทุกไตรมาส

> **แนวคิดสำคัญ (Key idea):** สำหรับ AMD การ "อ่านงบการเงิน" หมายถึง *การอ่านข้อมูลรายส่วนงาน* และแยกแยะ **ความเป็นจริงทางกระแสเงินสด (FCF)** ออกจาก **ภาพลวงตาทางบัญชี GAAP (ค่าตัดจำหน่าย / Amortization)** หากมองข้ามจุดนี้ คุณจะเข้าใจผิดว่าธุรกิจที่สร้างเงินสดได้ดีนี้แทบจะไม่มีกำไร

## ขั้นตอนที่ 5 · บริษัทมีมูลค่าเท่าใด? (การประเมินมูลค่า) (Step 5 · What's it worth? (valuation))

นี่คือส่วนที่ยากที่สุด เนื่องจากการประเมินมูลค่าจะถูกชี้นำโดย **สมมติฐานเกี่ยวกับการเร่งตัวของรายได้ AI (AI ramp)** การประเมิน DCF แบบหลายฉากทัศน์ (Scenario DCF) จาก FCF เริ่มต้นที่ ≈ $3.5 พันล้านดอลลาร์, WACC ≈ 10% (สูงกว่า Apple เนื่องจากมีความเสี่ยงมากกว่า), อัตราการเติบโตในระยะยาว (Terminal growth) ≈ 3% โดยปรับเปลี่ยนอัตราการเติบโตที่นำโดยกลุ่ม Data Center:

| ฉากทัศน์ (Scenario) | การเติบโตของรายได้/FCF (ปีที่ 1–10) | มูลค่าเหมาะสมโดยนัยต่อหุ้น (Implied fair value / share) |
|----------|--------------------------|----------------------------|
| **กรณีแย่ (Bear)** (กระแส AI ชะลอตัว, สงครามราคาแย่งชิงส่วนแบ่ง) | ~8% | ~$90 |
| **กรณีฐาน (Base)** (Data Center เติบโตอย่างต่อเนื่องสม่ำเสมอ) | ~18% | ~$140 |
| **กรณีดี (Bull)** (AMD ชิงส่วนแบ่ง AI ได้อย่างมีนัยสำคัญจริง) | ~28% | ~$210 |

**การตรวจสอบไขว้ด้วยอัตราส่วนเปรียบเทียบ (Multiples cross-check):** Forward P/E ที่ ~35–45× ถือว่าสูงในเชิงตัวเลขสัมบูรณ์ แต่ยัง *ต่ำกว่า* NVIDIA — ตลาดกำลังให้มูลค่า AMD ในฐานะผู้เล่นอันดับ 2 ที่มีศักยภาพ ขณะที่ P/S และ EV/EBITDA ก็สะท้อนเรื่องราวเดียวกัน: ตลาดตั้งราคาไว้สำหรับการเติบโตสูง

**สรุปภาพรวมมูลค่า:**

- **ช่วงมูลค่าที่เหมาะสม (Fair-value range):** กว้างมากที่ **~$90–210** โดยมีกรณีฐานอยู่ที่ **~$140**
- **ราคาหุ้นวันนี้ (Price today):** ~$135 — อยู่ใกล้เคียงกับกรณีฐานพอดี
- **ส่วนเผื่อความปลอดภัย (Margin of safety):** ค่อนข้างบาง และ *ช่วงการประเมินมูลค่ามีความกว้างมหาศาล* — การอ่านสถานการณ์ตามความจริงคือ "ผลลัพธ์ขึ้นอยู่กับความสามารถในการดำเนินงานจริง (Execution) ที่ยังไม่สามารถยืนยันได้ในขณะนี้"

> **แนวคิดสำคัญ (Key idea):** ช่วงมูลค่าเหมาะสมที่กว้างถึง ±60% ไม่ใช่ความล้มเหลวของการวิเคราะห์ — แต่มันคือภาพสะท้อนความเป็นจริงอย่างตรงไปตรงมาของการเดิมพันบนความไม่แน่นอนของการเติบโต วิธีรับมือที่ถูกต้องไม่ใช่การพยายามคำนวณตัวเลขให้ดูแม่นยำเกินจริง (False precision) แต่เป็นการ **กำหนดขนาดสถานะลงทุนให้เล็กลงและวางแผนทยอยสะสมหุ้นเป็นไม้ๆ (Scale-in plan)** (ขั้นตอนที่ 7–8) ซึ่งจะให้ผลตอบแทนคุ้มค่าแก่ผู้ที่มีความอดทน

## ขั้นตอนที่ 6 · อ่านทิศทางตลาด (จังหวะเวลาและการยืนยันสัญญาณ) (Step 6 · Read the market (timing & confirmation))

วิเคราะห์ผ่าน [มุมมองสภาวะตลาด (Market lens)](learning-market.html) — AMD เป็นหุ้นธีม AI ที่มีค่าเบต้าสูง (High-beta) และมีปริมาณการซื้อขายหนาแน่น ดังนั้นอารมณ์ความรู้สึกของตลาด (Sentiment) จึงมีความสำคัญอย่างยิ่ง:

- **แนวโน้ม / โมเมนตัม (Trend / momentum):** หุ้นกลุ่ม AI มักวิ่งตามแนวโน้มอย่างรุนแรงทั้งสองทิศทาง หากราคาพุ่งขึ้นสูงกว่าเส้นค่าเฉลี่ย 200 วันมากเกินไป แสดงถึงความหวังในแง่ดีที่กระจุกตัวหนาแน่น (Crowded optimism) — จงอย่าไล่ราคาตอนที่ราคาดีดตัวแรง
- **ออปชัน (Options):** ค่าความผันผวนแฝง (Implied Volatility - IV) มักจะ **สูงมาก** ในช่วงประกาศผลประกอบการ (`options-analysis`) — ตลาดคาดการณ์ว่าจะเกิดการแกว่งตัวของราคาอย่างรุนแรง และค่าพรีเมียมของออปชันจะมีราคาแพง
- **การวางสถานะของนักลงทุน (Positioning):** ตรวจสอบกระแสเงินทุนของสถาบัน (`institutional-ownership`) และกิจกรรมการซื้อขายของผู้บริหาร/คนวงใน (`insider-trading`) การที่หุ้นถูกถือครองโดยนักลงทุนรายย่อยหรือกลุ่มที่เน้นโมเมนตัมเป็นสัดส่วนสูงอาจขยายวงการปรับฐาน (Drawdown) ให้รุนแรงยิ่งขึ้น
- **ตัวเร่งทางธุรกิจ (Catalysts):** ผลประกอบการรายไตรมาส, การคาดการณ์รายได้ของชิป MI300 (Revenue guidance) และข่าวคำสั่งซื้อจากลูกค้าระดับ Hyperscalers คือปัจจัยขับเคลื่อนหลัก (`catalyst-calendar`, `earnings-call-analysis`) ปัจจัยเหล่านี้สร้างได้ทั้งความเสี่ยงและจังหวะการย่อตัวลงมาให้เข้าซื้อ

## ขั้นตอนที่ 7 · การตัดสินใจและกำหนดขนาดสถานะลงทุน (Step 7 · Decide & size)

สรุปการตัดสินใจลงทุน (อิงตามแกนเดียวกับ [กล่องสัญญาณการลงทุน (Signal block)](concepts.html)):

| หัวข้อ (Field) | การประเมิน (Read) | เหตุผล (Why) |
|-------|------|-----|
| **สัญญาณ (Signal)** | เป็นบวก / ขาขึ้น (Bullish - ด้านการเติบโต) | ปัจจัยหนุนด้าน AI/เซิร์ฟเวอร์มีอยู่จริงและการแย่งชิงส่วนแบ่งตลาดทำได้ต่อเนื่อง |
| **ระดับความมั่นใจ (Confidence)** | **ปานกลาง (Medium)** | มีความเป็นวัฏจักร, ขึ้นอยู่กับผลงานการดำเนินงานจริง, ปราการทางธุรกิจยังต้องแข่งขัน |
| **กรอบเวลา (Horizon)** | ระยะยาว (Long-term 3–5 ปี) | การเร่งตัวของธุรกิจ AI เป็นเรื่องราวที่ต้องใช้เวลาขับเคลื่อนหลายปี |
| **การปฏิบัติการ (Action)** | **ซื้อไม้แรกเพื่อเริ่มสถานะ (Starter) แล้วรอสะสมเพิ่มเมื่อราคาย่อตัว** | ราคาอยู่ใกล้เคียงกับมูลค่าพื้นฐานกรณีฐาน; ช่วงผลลัพธ์ที่เป็นไปได้กว้างมาก |
| **ระดับความเชื่อมั่น (Conviction)** | ปานกลาง (Moderate) | ช่วงมูลค่ากว้าง + ปราการทางธุรกิจแคบกว่าหุ้นที่เป็นพอร์ตหลัก |

**ขนาดสถานะลงทุน (Position size) — นี่คือจุดที่ AMD และ Apple แตกต่างกันมากที่สุด** เนื่องจากความไม่แน่นอนและความผันผวนอยู่ในระดับสูง จึงควรปฏิบัติต่อ AMD ในลักษณะเดียวกับการปรับหน้าปัดของ *หุ้นเติบโตที่ยังไม่มีกำไร (Pre-profit growth)* ตามที่ระบุไว้ใน Playbook:

- ขนาดเป้าหมาย: **≤ 3%** ของพอร์ตโฟลิโอ (จัดเป็นหุ้นส่วนเสริม / Satellite ไม่ใช่หุ้นแกนหลัก / Core)
- ขีดจำกัดสูงสุดเด็ดขาด (Hard cap): **≤ 4%** และห้ามถัวเฉลี่ยขาลงเกินกว่าแผนที่กำหนดไว้เด็ดขาด
- เตรียมพร้อมรับ **การแกว่งตัวของราคา ±30–40%** และกำหนดขนาดสถานะเพื่อไม่ให้ผลประกอบการที่แย่เพียงไตรมาสเดียวบีบให้คุณต้องขายตัดขาดทุนด้วยความตื่นตระหนก (Panic sell)

*ใน Plugin:* ใช้งาน `result-validator` — สำหรับหุ้นที่ผลลัพธ์ขึ้นอยู่กับการดำเนินงานจริงมากขนาดนี้ หากได้คะแนนคุณภาพข้อมูลหรือความสอดคล้องของสัญญาณต่ำ ควรปรับลดขนาดสถานะลงทุนลงไปอีก

## ขั้นตอนที่ 9 · ติดตามสมมติฐานการลงทุน (Step 9 · Track the thesis)

**รอบความถี่ในการทบทวน (Review cadence):** ทุกครั้งที่มีการรายงานผลประกอบการ + เมื่อมีข่าวสำคัญเกี่ยวกับ AI หรือลูกค้ารายใหญ่

**ตัวชี้วัดผลงานหลัก (KPIs) ที่สมมติฐานนี้ต้องพึ่งพา:**

| ปัจจัยที่ต้องจับตา (Watch) | สมมติฐานยังคงใช้ได้หาก… (Thesis stays intact if…) |
|-------|-------------------------|
| การเติบโตของรายได้ Data Center | ยังคงเร่งตัวขึ้นเมื่อเทียบปีต่อปี (YoY) |
| รายได้จาก MI300 / AI GPU | ทำได้ตามเป้าหรือสูงกว่าเป้าหมายที่ประกาศไว้ (Guidance) |
| แนวโน้มอัตรากำไรขั้นต้น (Gross-margin trend) | ปรับตัวสูงขึ้น (การปรับสัดส่วนผลิตภัณฑ์ได้ผล) |
| ส่วนแบ่งตลาด Server CPU เทียบกับ Intel | ส่วนแบ่งตลาดของ EPYC ยังคงเพิ่มขึ้นต่อเนื่อง |
| ประมาณการล่วงหน้าและยอดคำสั่งซื้อคงค้าง (Guidance & backlog) | ผู้บริหารปรับเพิ่มประมาณการ ไม่ใช่ปรับลดลง |

**เงื่อนไขลบล้างสมมติฐาน (Thesis-invalidation triggers) — ขาย / ประเมินใหม่ทันทีหาก:**

- การเติบโตของ Data Center **ชะลอตัวลงอย่างรวดเร็ว** หรือมีการปรับลดประมาณการลง
- การเติบโตของ MI300/AI **พลาดเป้าที่ประกาศไว้** ติดต่อกันตั้งแต่ 2 ไตรมาสขึ้นไป
- อัตรากำไรขั้นต้น **หยุดนิ่งหรือลดลง** (แรงกดดันด้านราคาจาก NVIDIA / สัดส่วนสินค้ากลับทิศ)
- NVIDIA **ขยาย** ความเป็นผู้นำด้านซอฟต์แวร์ทิ้งห่างออกไป และลูกค้าหันมาใช้ CUDA เป็นมาตรฐานหลัก (ช่องว่างปราการกว้างขึ้น ไม่ใช่แคบลง)
- สมมติฐานประโยคเดียวที่เขียนไว้ตั้งแต่แรกไม่เป็นความจริงอีกต่อไป

## ขั้นตอนที่ 10 · วินัยในการขาย (Step 10 · The sell discipline)

ใช้เหตุผล 4 ข้อเดียวกับใน Playbook — แต่สำหรับ AMD เหตุผลข้อที่ 1 (สมมติฐานพัง) คือข้อที่ต้องยึดมั่นอย่างเคร่งครัดที่สุด เพราะเรื่องราวการเติบโตของ AI สามารถพลิกผันได้อย่างรวดเร็ว:

1. **สมมติฐานการลงทุนพังลง (Thesis broke)** — เกิดเงื่อนไขกระตุ้นข้อใดข้อหนึ่งข้างต้น (เช่น การเติบโตของ DC หยุดชะงัก, ช่องว่างปราการทางธุรกิจกว้างขึ้น) ให้ขายออกทันทีโดยไม่ต้องสนใจระดับราคา
2. **พบโอกาสการลงทุนที่ดีกว่า (A better opportunity)** — เงินทุนมีจำกัด หุ้นส่วนเสริม (Satellite) ต้องพิสูจน์ตัวเองเพื่อรักษาตำแหน่งในพอร์ต
3. **มูลค่าแพงเกินไปอย่างยิ่งยวด (Extreme overvaluation)** — ราคาพุ่งทะลุเกินกว่ากรณีดี (Bull case) ไปมาก ให้แบ่งขายทำกำไร (Trim)
4. **การบริหารความเสี่ยง (Risk management)** — มูลค่าหุ้นเติบโตจนเกินเพดาน 4% ของพอร์ต ให้ขายปรับสัดส่วนกลับมาที่เป้าหมาย

> **แนวคิดสำคัญ (Key idea):** สำหรับหุ้น AI ยอดนิยม ความอันตรายไม่ได้อยู่ที่การเข้าซื้อ — แต่อยู่ที่ *การตกหลุมรักหุ้น* จนปล่อยให้สถานะเก็งกำไรเสริม (Satellite) พองโตกลายเป็นหุ้นหลักของพอร์ตโดยที่พื้นฐานยังไม่คู่ควร เพดานความเสี่ยงและเงื่อนไขลบล้างที่จดไว้เป็นลายลักษณ์อักษรคือสิ่งที่จะปกป้องคุณจากความรู้สึกเคลิบเคลิ้มในตลาด (Euphoria)

## AMD เทียบกับ Apple: กระบวนการลูปเดียวกัน แต่ปรับตั้งค่าต่างกัน (AMD vs. Apple: same loop, different dials)

| | Apple (Playbook) | AMD (กรณีศึกษานี้) |
|---|-----------------|-----------------|
| ลักษณะธุรกิจ (Business) | ธุรกิจเติบโตทบต้นแบบเติบโตเต็มวัย (Mature compounder) | เติบโตตามวัฏจักร (Cyclical growth) |
| ปราการทางธุรกิจ (Moat) | กว้างและแข็งแกร่ง (ระบบนิเวศ / Ecosystem) | ผสมผสาน — ตลาดกึ่งผูกขาด CPU แต่ใน AI-GPU ยังต้องแข่งขันขับเคี่ยว |
| คุณภาพของธุรกิจ (Quality) | ROIC สูงมาก | ROIC ปานกลางและผันผวนตามวัฏจักร |
| ช่วงการประเมินมูลค่า (Valuation range) | ค่อนข้างแคบ | กว้างมาก (±60%) |
| การตัดสินใจลงทุน (Decision) | รอจังหวะราคาที่ดีกว่านี้ | ซื้อไม้แรกเริ่มต้น (Starter) ขนาดเล็ก + รอทยอยซื้อเพิ่ม |
| ขนาดสถานะลงทุน (Size) | หุ้นหลักในพอร์ต (Core ~5%) | หุ้นส่วนเสริม (Satellite ≤3%) |
| แผนการซื้อขาย (Trading plan) | กรอบขั้นบันไดแคบกว่า | กรอบขั้นบันไดกว้างกว่าและแบ่งไม้เล็กกว่า |
| โฟกัสเงื่อนไขการขาย (Sell trigger focus) | ปราการทางธุรกิจ / ภาคบริการ (Services) | การเร่งตัวของ Data Center + ทิศทางอัตรากำไร |

> **บทเรียนที่ได้รับ (The lesson):** กระบวนการไม่เคยเปลี่ยนแปลง — ตั้งแต่สมมติฐาน, แผนวิจัย, การวิเคราะห์, การตัดสินใจ, แผนการเทรด ไปจนถึงการติดตามผล สิ่งที่เปลี่ยนไปมีเพียง **วิธีที่คุณหมุนปรับหน้าปัด** เพื่อให้เข้ากับธุรกิจที่มีความเสี่ยงและความไม่แน่นอนสูงกว่า และนั่นคือหัวใจสำคัญของการมีกระบวนการลงทุนที่เป็นระบบ

## ประเด็นสรุปสำคัญ (Key takeaways)

- **กระบวนการลูป 10 ขั้นตอนเดียวกัน** สามารถใช้ได้ผลดีทั้งกับหุ้นเซมิคอนดักเตอร์ AI ที่ผันผวน และหุ้นเติบโตทบต้นที่มั่นคง — คุณเพียงแค่ต้องปรับขนาดสถานะ, กรอบราคา และเงื่อนไขการขายให้เข้ากับระดับความเสี่ยง
- สำหรับ AMD ด้าน "คุณภาพ" จัดว่า **ผ่านแบบมีข้อควรระวัง**: มีตลาดกึ่งผูกขาด CPU อยู่จริง แต่มีปราการ AI-GPU ที่ **ยังต้องแข่งขันแย่งชิง** เมื่อเทียบกับ CUDA ของ NVIDIA
- จงแยกแยะ **เงินสดจริง (FCF) ออกจากภาพลวงตาทางบัญชี GAAP** (ค่าตัดจำหน่าย Xilinx) มิฉะนั้นคุณจะประเมินความสามารถในการทำกำไรผิดพลาด
- **ช่วงมูลค่าเหมาะสมที่กว้าง** คือการสะท้อนความจริงอย่างตรงไปตรงมา — จงรับมือด้วย **ขนาดสถานะที่เล็กและแผนทยอยสะสมหุ้น** ไม่ใช่การหลอกตัวเองด้วยตัวเลขคำนวณที่แม่นยำเกินจริง
- ให้คำมั่นล่วงหน้ากับ **เงื่อนไขลบล้างสมมติฐาน** (การเติบโตของ Data Center, การเร่งตัวของ MI300, ทิศทางอัตรากำไร) เพื่อไม่ให้อารมณ์ความรู้สึกต่อกระแส AI ที่เปลี่ยนไปทำให้คุณหาเหตุผลเข้าข้างตัวเอง
